# V1.0.0 visual production source

## Art direction

Original characters, not existing intellectual property. A bright, sunlit miniature workshop with realistic fur and feathers, friendly anthropomorphic expressions, and professional engineering props.

| Role | Character | Fixed identifiers |
| --- | --- | --- |
| Router guide | Brown river otter | Cream muzzle, small round ears, teal utility vest, brass compass badge |
| Developer / Host decision-maker | Ivory rabbit | Long ears, round dark glasses, coral knit cardigan |
| Verification / tool helper | Tawny owl | Cream face, yellow apron, navy side satchel |

Palette: ivory `#FFF8ED`, teal `#168C84`, coral `#F27A5E`, sunflower `#F4BD43`, navy `#18384A`.

The animal roles are a visual metaphor, not autonomous Python semantic agents. Exact contracts live in the README captions and version-controlled architecture sources.

## Assets and sequence

- `hero.png`: many capabilities become a task-relevant plan with the Router's guidance.
- `story-a.png`: panels **1, 2, 3, 4**, left to right, then top to bottom.
- `story-b.png`: panels **5, 6, 7, 8**, continuing the same story.
- `principles.png`: panels **1, 2, 3, 4**, matching the four policy captions.
- `architecture.svg`: accessible, locally maintained diagram embedded in both READMEs.
- `architecture.mmd`: editable Mermaid flow with the empty-Execution-Needs branch.

The tutorial follows overwhelm, task analysis, trusted discovery, Host decisions, handoff/coverage and execution needs, a frozen selection receipt, actual execution, and separate verification evidence. The receipt appears before execution: FINALIZED is not execution success.

## Production method

The built-in image-generation capability produced the hero and three comics. The hero was the shared visual reference for every comic. A subsequent image-generation edit added only the required reading-order badges and adjusted safe framing. Number badges are navy with white digits, placed at each panel's top-left; precise prose stays outside the artwork.

The selected diagram capability was actually used to create an [editable FigJam flow](https://www.figma.com/board/jxFG8pH1d2wdMmp2897LYQ). The repository SVG and Mermaid source are the portable, reviewable versions and do not require Figma access.

No private inventory, credentials, device identifiers, or machine-specific paths are part of the artwork or these public production notes. Local routing evidence is not an image source.

## Acceptance boundary

Automated checks verify local references, PNG dimensions, strict text encoding, and SVG/XML structure. Human-style visual inspection must separately inspect the final assets and rendered README at desktop and narrow widths for sequence, legibility, cropping, character continuity, watermark, and private information. Structural checks alone do not prove visual quality.
