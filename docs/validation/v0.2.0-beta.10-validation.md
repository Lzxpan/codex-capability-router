## Evidence boundaries

- Windows permission errors are simulated at the filesystem boundary; real ACL
  denial behavior is NOT VERIFIED.
- Fixture Host responses prove schema, binding, completeness, and rejection
  behavior. They do not prove real LLM consideration or semantic accuracy.
- COMPLETE means every candidate in the supplied pool has a resolved Host
  disposition. It does not certify discovery of every installed capability.
- Automatic per-task Host integration, full installed App/MCP inventory, real
  Provider authorization/invocation, production, hardware, performance targets,
  and persistent preference learning are NOT VERIFIED.
- This source release does not update other global Skill/runtime installations.
- GitHub rendering in a browser is NOT VERIFIED. Remote Git identity and a fresh
  clone are checked separately during publishing.
- Original supplied audit/plan files remain local and are excluded from publishing.
  Historical release reports remain historical evidence.
