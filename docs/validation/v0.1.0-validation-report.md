## 11. Phase 5E — Route-only selection semantics

本階段固定 route-only selection 與 downstream execution suppression 的邊界，
不新增 routing scenario，也不新增 execution engine：

- Router controller 及其 aliases 永久排除於 downstream task selection。
- `routing_support` internal discovery/support capability 不進 task selection。
- `execution_allowed=false` 的 route-only request 仍選擇 target-task capability，
  但只回傳 selection，不執行 selected capability。
- Selected Capability Explanation 保留 `Selected Capabilities`、適用時的
  `Selected Skills`、Function、PRIMARY/OPTIONAL 與 deterministic Why selected；
  recommendation-only 維持獨立，不混入 selected output。
